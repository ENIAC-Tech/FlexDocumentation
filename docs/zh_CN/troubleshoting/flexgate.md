# FlexGate

[FlexGate](https://flexgate.enilinx.com/) is an online sharing platform where you can easily find or share your own Profiles, Iconpacks, Pages, and Plugins.

## 从 FlexGate 安装

![1744946445046](/image/flexgate/1744946445046.png)

从 FlexGate 安装配置文件、图标包、页面或插件非常简单。只需确保 FlexDesigner 正在运行，然后点击获取即可自动下载和安装。

## 将配置文件、图标包和页面上传到 FlexGate

![1744946552525](/image/flexgate/1744946552525.png)

转到您的个人资料页面，点击您想要上传的项目。

![1744946938052](/image/flexgate/1744946938052.png)

上传前，您需要填写一些信息：

- 标题：您内容的名称 - 保持简洁并清楚描述其用途
- 图片：我们建议提供几张截图来帮助用户了解您内容的功能
- 类别：为您的内容选择最合适的类别
- 操作系统：选择您内容支持的操作系统
- 版本：您内容的版本号（与 FlexDesigner 版本无关）
- 描述：详细说明您内容的功能

## 将插件上传到 FlexGate

![1744946820834](/image/flexgate/1744946820834.png)

上传插件的工作方式略有不同。我们要求插件托管在 GitHub 上。只需输入您的仓库 URL，FlexGate 将验证其有效性。

> Make sure your repository was created with FlexCLI and has a valid plugin structure. Check out the [SDK documentation](../sdk/) to learn how to create custom plugins

![1744946889859](/image/flexgate/1744946889859.png)

上传前，您需要填写一些信息：

- 图片：我们建议提供几张截图来帮助用户了解您插件的功能
- 类别：为您的插件选择最合适的类别

## 常见问题
**问：什么是 FlexGate？**

**答：** FlexGate 是一个在线共享平台，您可以轻松找到或分享自己的配置文件、图标包、页面和插件。

**问：我可以通过 FlexGate 发布付费内容吗？**

**答：** 支付系统仍在开发中。我们计划在未来的更新中添加此功能。

**问：上传到 FlexGate 的内容侵犯了我的权利。**

**答：** 我们认真对待知识产权。请将任何侵权内容的详细信息发送到 contact@eniacelec.com，我们将及时处理您的关切。

**问：我可以在哪里与其他创作者讨论和分享？**

**答：** 我们建议加入我们的 [Discord 社区](https://discord.com/invite/7STSjmBpKT)，在那里您会找到许多志同道合的创作者。

**问：如何获得客户支持或提交建议？**

**答：** 请通过 contact@eniacelec.com 联系我们，或直接联系我们 Discord 社区的管理员。我们将尽快回复。
