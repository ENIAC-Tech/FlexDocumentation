# 音频混音器

音频混音器按键允许单独控制不同应用程序的音频音量。

此按键仅在 FlexDesigner 运行时工作。目前此按键仅在 Windows 版本的 FlexDesigner 中存在。

![1744987068780](/image/audio_mixer/1744987068780.png)

## 在 FlexDesigner 中

![1744987057470](/image/audio_mixer/1744987057470.png)

在功能页面中，显示当前运行应用程序的列表。对于每个应用程序，在列表右侧边缘附近都有一个复选框。只有选中的应用程序才会被音量滑块控制。

## 在 Flexbar 上

在 Flexbar 上拖动滑块来调整选中应用程序的音频音量。
