# 麦克风静音

麦克风静音键允许您快速切换系统麦克风的开启或关闭。当您按下此键时，计算机的麦克风将在静音与非静音之间切换。

此功能仅在 FlexDesigner 运行时有效。如果您需要在未运行 FlexDesigner 的情况下控制麦克风静音，可以考虑使用系统自带的多媒体静音键。请注意，这些方式显示的状态可能无法与 Flexbar 指示保持同步。

## 在 FlexDesigner

除了外观自定义选项之外，此键在 FlexDesigner 中没有其他设置。

## 在 Flexbar

点击 Flexbar 上的麦克风静音键可切换麦克风的静音状态。如果您通过其他方式（如键盘快捷键或系统托盘）更改了麦克风静音状态，Flexbar 按键也会自动更新以显示正确的静音状态。
