# 播放信息

仅限 Windows

显示当前媒体的播放状态，包括封面、播放进度、标题和艺术家。显示的信息与 Windows 媒体信息同步。

## 在 FlexDesigner

除标准外观自定义选项外，此键在 FlexDesigner 中没有其他设置。

![20251023-124246](/image/playback_info/20251023-124246.jpg)


## 在 Flexbar

![playback_info](/image/playback_info/playback_info.png)

点击 Flexbar 上的播放/暂停键可以控制媒体应用的播放。如通过其他方式（如键盘快捷键或在媒体播放器中点击）暂停或恢复播放，Flexbar 按键将自动更新以显示当前播放/暂停状态。

> 你可以自由自定义播放和暂停状态的外观。
