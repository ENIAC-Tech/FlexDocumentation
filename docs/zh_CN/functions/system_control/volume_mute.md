# 扬声器静音

扬声器静音键允许您快速切换系统的音频输出在静音与非静音之间。当您按下此键时，计算机扬声器将在发出声音和静音状态之间切换。

此功能仅在 FlexDesigner 运行时有效。如果您需要在未运行 FlexDesigner 的情况下控制扬声器静音，可以考虑使用系统自带的多媒体静音键。但这些方式显示的状态可能无法与 Flexbar 指示保持同步。

## 在 FlexDesigner

除了标准的外观自定义选项外，该键在 FlexDesigner 中没有其他额外设置。

## 在 Flexbar

点击 Flexbar 上的扬声器静音键可切换扬声器的静音状态。如果您通过其他方式（如键盘快捷键或系统面板）更改了扬声器静音状态，Flexbar 按键也会自动更新以显示当前的静音状态。
