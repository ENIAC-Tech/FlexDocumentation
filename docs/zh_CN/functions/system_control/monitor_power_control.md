# 显示器电源控制

此按键允许使用 DDC/CI 协议关闭外部显示器。大多数显示器在某种程度上都支持此协议。此按键还允许同时控制多个显示器。请注意，此按键无法重新打开显示器，因为显示器关闭后与显示器的连接会丢失。此按键仅在 FlexDesigner 运行时工作。

![1745502329080](/image/monitor_power_control/1745502329080.png)

## 在 FlexDesigner 中

![1745502353165](/image/monitor_power_control/1745502353165.png)

此按键的功能选项卡中会显示已连接显示器的列表。它还显示显示器支持的控制。每个显示器的右侧都有一个复选框。只有选中的显示器才会被此按键控制。

## 在 Flexbar 上

按按键关闭选中的显示器。
