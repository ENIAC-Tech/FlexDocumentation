# 播放/暂停

仅限 Windows

播放/暂停键允许您快速切换系统上的媒体播放。当您按下此键时，会向当前活跃的媒体应用（如音乐播放器或视频播放器）发送播放/暂停指令，实现在播放和暂停状态之间的切换。

该功能仅在 FlexDesigner 运行时有效。如果您需要在没有 FlexDesigner 的情况下使用播放/暂停功能，可以使用系统自带的媒体键，但这些键可能无法与 Flexbar 指示器保持同步。

## 在 FlexDesigner

除了标准的外观自定义选项外，该键在 FlexDesigner 中没有其他额外设置。

## 在 Flexbar

<img src="/image/play_pause/Pause.png" alt="Pause" width="200"/>

在 Flexbar 上点击播放/暂停键可控制媒体应用程序的播放。当通过其他方式（例如键盘快捷键或在媒体播放器内点击）暂停或恢复播放时，Flexbar 按键也会更新显示正确的播放/暂停状态。

> 您可以自由自定义播放和暂停状态的外观。
