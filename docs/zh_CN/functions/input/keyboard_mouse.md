# 键盘和鼠标

键盘和鼠标按键通过一次点击发送按键和鼠标事件。一个用例是使用它来实现像 'Ctrl + 点击' 或 'Ctrl + 滚动' 这样的快捷键。

此功能模拟一组标准 USB 键盘和鼠标。它可以在任何设备上工作，无需运行 FlexDesigner。

![1744983810565](/image/keyboard_mouse/1744983810565.png)

## 在 FlexDesigner 中

This key provides the same set of settings as the keyboard key and the mouse key. Check [keyboard ](./keyboard)and [mouse ](mouse)pages for details.

> 此按键中的键盘模式仅支持单击

![1744983863690](/image/keyboard_mouse/1744983863690.png)

## 在 Flexbar 上

在 Flexbar 上按下按键以触发定义的操作。
