# 剪贴板

剪贴板功能允许您通过一次点击快速将文件、图像或文本复制到剪贴板，方便您在任何需要的地方粘贴。

![1745471330502](/image/clipboard/1745471330502.png)

## 在 FlexDesigner 中

![1745471367411](/image/clipboard/1745471367411.png)

要开始使用，请点击右侧的 + 图标创建新的剪贴板项目。

![1745471398426](/image/clipboard/1745471398426.png)

- 名称：为您的剪贴板项目命名，以便稍后轻松识别
- 文本：输入要复制到剪贴板的文本内容
- 文件或图像：选择要复制到剪贴板的文件或图像

创建后，只需选择您的剪贴板项目即可完成设置。

## 在 Flexbar 上

只需按下相应的按钮，Flexbar 就会自动将您的内容复制到剪贴板并粘贴。
