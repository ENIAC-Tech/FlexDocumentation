# 贴纸包

贴纸包按键在按下时从贴纸包中插入贴纸（如表情包或任何图像）到活动输入框中。

## 在 FlexDesigner 中

![1744984574600](/image/sticker_pack/1744984574600.png)

贴纸按贴纸包组织。贴纸包是可在 FlexDesigner 中使用的所有贴纸的库，这意味着为单个按键配置的贴纸包在所有贴纸包按键之间共享。软件提供了一些用于组织贴纸包的基本功能（按软件中按钮的顺序）：

- 导入贴纸包：从 FlexDesigner 导入之前导出的贴纸包
- 添加新图像：在计算机上选择图像文件，然后将其添加到贴纸包
- 从剪贴板添加：将之前复制的图像粘贴到贴纸包中
- 导出贴纸包：将当前贴纸包导出到单个文件以进行备份或共享

要从贴纸包中删除图像，请右键单击图像并点击「删除」。要从贴纸包中删除多个图像，请将光标悬停在图像上时使用图像右上角的复选框选择图像，右键单击任何图像，点击「删除所有选中的」。

值得注意的是，这些操作与前景设置中使用的图标包相同。但是，与图标包不同，它不支持管理多个贴纸包。

每个按键只能分配一个贴纸。从贴纸包中单击所需的贴纸来选择。它应该显示在贴纸包区域顶部的预览区域中。

## 在 Flexbar 上

在 Flexbar 上按下按键将定义的贴纸插入到计算机上当前活动的输入框中。

## 提示

虽然软件支持多种格式，但兼容性也取决于目标软件（例如，当插入到完全不支持 GIF 的消息软件中时，Flexbar 无法在那里神奇地插入动画 GIF）。为了获得最大兼容性，建议仅使用 JPEG 和 GIF 格式。
