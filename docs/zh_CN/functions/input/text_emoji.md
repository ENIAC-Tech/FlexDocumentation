# 文本/表情符号

文本/表情符号按键将文本插入到计算机上的活动输入框中。此按键支持表情符号，但需要运行 FlexDesigner。另请参阅不支持表情符号但也不依赖 FlexDesigner 的文本按键。

![1744984750189](/image/text_emoji/1744984750189.png)

## 在 FlexDesigner 中

![1744984738429](/image/text_emoji/1744984738429.png)

文本或表情符号（或这些内容在一行或多行中的任何组合）可以在 FlexDesigner 的功能选项卡中定义。表情符号可以通过第三方输入法/面板（如 macOS 上的表情符号选择器）插入，或使用输入框右侧的表情符号按钮。要放大输入框，请将虚线三角形拖到输入框的右下角。

## 在 Flexbar 上

按按键将定义的文本/表情符号插入到活动输入框中。
