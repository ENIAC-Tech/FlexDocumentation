# 文本

文本按键将文本插入到计算机上的活动输入框中。此按键模拟在标准 USB 键盘上按下的按键，因此只能支持可以直接在键盘上输入的内容。如果需要其他字符，请考虑使用文本/表情符号按键。

![1744984770513](/image/text/1744984770513.png)

## 在 FlexDesigner 中

![1744984788098](/image/text/1744984788098.png)

文本可以在 FlexDesigner 的功能选项卡中定义。要放大输入框，请将虚线三角形拖到输入框的右下角。

## 在 Flexbar 上

按按键将定义的文本插入到活动输入框中。
