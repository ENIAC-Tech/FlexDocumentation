# 多媒体

多媒体按键发送多媒体按键操作，就像在物理键盘上按下一样。

此功能模拟带有多媒体按键的标准 USB 键盘。它可以在任何设备上工作，无需运行 FlexDesigner。

![1744984037291](/image/multimedia/1744984037291.png)

## 在 FlexDesigner 中

![1744984021980](/image/multimedia/1744984021980.png)

要按下的按键可以在 FlexDesigner 的按键选项卡中配置。点击菜单按钮选择按键。

## 在 Flexbar 上

在 Flexbar 上按下按键以触发定义的操作。
