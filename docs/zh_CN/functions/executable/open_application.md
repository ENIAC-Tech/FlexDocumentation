# 打开应用程序

打开应用程序按键在按下时打开用户定义的应用程序或文件夹。

![1744946027052](/image/open_application/1744946027052.png)

## 在 FlexDesigner 中

要打开的应用程序或文件夹可以在 FlexDesigner 的功能选项卡中定义。路径输入框右侧有 3 个按钮。第一个允许选择文件夹，第二个允许选择要启动的应用程序。第三个按钮允许在将新配置文件上传到 Flexbar 之前在计算机上直接进行测试运行。测试运行应该执行与在 Flexbar 上按下按键相同的操作。

![1744712900295](/image/open_application/1744712900295.png)

1. 选择要打开的路径，将在 Windows 上用文件资源管理器、在 MacOS 上用 Finder、在 Linux 上用默认文件管理器打开
2. 选择要打开的文件或应用程序
3. 在您的计算机上测试运行

## 在 Flexbar 上

按按键启动在 FlexDesigner 中定义的应用程序或文件夹。
