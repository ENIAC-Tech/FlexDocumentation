# 热力图

热力图功能显示特定 GitHub 用户的贡献热力图。

![1744983539002](/image/heatmap/1744983539002.png)

## 在 FlexDesigner 中

要使用此功能，需要在 FlexDesigner 中配置 GitHub 用户名。此外，可以通过点击用户名输入框旁边的刷新按钮手动刷新热力图。

![1744983514568](/image/heatmap/1744983514568.png)

## 在 Flexbar 上

热力图将显示在为该功能分配的区域中。此按键没有交互操作。

![1744983523673](/image/heatmap/1744983523673.png)
