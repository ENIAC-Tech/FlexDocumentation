# 宏播放器

宏播放器按键在按下时执行记录的键盘和鼠标宏。

![1744986195408](/image/macro_player/1744986195408.png)

## 在 FlexDesigner 中

![1744986859802](/image/macro_player/1744986859802.png)

1. 在 Flexbar 上打开录制器界面
2. 当前鼠标坐标
3. 当前按下的按键
4. 选择保存的录制
5. 编辑/删除录制
6. 测试选定的录制，**注意：点击此按钮将立即播放您录制的宏**
7. 调整播放速度
8. 设置播放录制的次数

点击 `OPEN RECORDER` 开始录制宏。您需要在 Flexbar 上完成录制。

![1744986676793](/image/macro_player/1744986676793.png)

1. 开始/停止录制
2. 录制持续时间 (MM:SS)
3. 当前鼠标坐标
4. 当前按下的按键
5. 保存此录制
6. 播放/停止此录制

保存录制后，它将出现在功能选项卡中，您可以在其中选择和使用之前录制的宏。

选择录制的宏并上传到 Flexbar 后，只需在 Flexbar 上按此按键即可播放宏。
