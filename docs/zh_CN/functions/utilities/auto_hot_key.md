# Auto Hot Key

此功能允许您通过单击执行 [Auto Hot Key](https://www.autohotkey.com/) V2 脚本。

[Auto Hot Key](https://www.autohotkey.com/) 是一个强大的 Windows 实用工具，可以控制您的鼠标、键盘、应用程序、系统媒体等。

![1745502544477](/image/auto_hot_key/1745502544477.png)

## 在 FlexDesigner 中

![1745502618520](/image/auto_hot_key/1745502618520.png)

功能选项卡提供了一个简单的代码编辑器，您可以在其中编辑 AHK 脚本。

编辑器右上角有一个测试运行按钮，用于快速测试您的脚本是否正常工作。

## 在 Flexbar 上

单击此按键将立即运行您输入的 AHK 脚本。
