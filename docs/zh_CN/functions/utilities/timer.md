# 计时器

倒计时计时器，可以在计时器开始或结束时执行一系列操作。您可以为计时器结束时配置警报。

## 在 FlexDesigner 中

![1745511449741](/image/timer/1745511449741.png)

1. 设置倒计时持续时间
2. 选择倒计时结束时的警报类型：禁用、按钮警报或全屏警报
3. 隐藏倒计时时间显示的选项
4. 倒计时时间显示的位置
5. Actions to execute when the countdown starts/ends, configured the same way as [Sequenced Keys](../more/sequenced_keys)

## 在 Flexbar 上

倒计时开始时，半透明黑色覆盖层显示进度。倒计时结束时将发出警报声。
