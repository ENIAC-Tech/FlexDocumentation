# 工作区

工作区按键将窗口布局排列到预定义状态。它的工作原理是首先在 FlexDesigner 中捕获窗口布局（工作区）。之后，当按下按键时，它将窗口布局恢复到之前记录的状态。这样当您需要开始工作时，只需按此按键设置工作区，就可以立即开始工作。此功能仅在 FlexDesigner 运行时有效。

## 在 FlexDesigner 中

![1744986124408](/image/workspace/1744986124408.png)

当此按键首次添加到页面时，FlexDesigner 会自动捕获/记录当前窗口布局。窗口布局显示在功能选项卡的列表中。

列表右上方有两个按钮：重新捕获和测试运行。第一个用当前窗口布局替换现有列表。测试运行按钮按照列表中定义的方式排列窗口，就像在 Flexbar 上按下按键一样。

![1744986153322](/image/workspace/1744986153322.png)

对于每个窗口，可以手动修改边界（XY 坐标、宽度、高度和缩放）。这些输入框右侧有 4 个按钮：刷新、编辑、删除和测试运行。刷新按钮重新捕获所选窗口的位置。编辑按钮为窗口提供额外设置，如应用程序路径和用于打开窗口的策略（始终打开新的、查找现有的等）。删除按钮从列表中移除窗口。测试运行按钮恢复此特定窗口的位置和大小以进行测试。
