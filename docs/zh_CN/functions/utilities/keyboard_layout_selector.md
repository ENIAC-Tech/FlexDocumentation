# 键盘布局选择器

键盘布局选择器按键允许在按下时切换到预定义的键盘布局/输入法。当计算机上启用了多个键盘布局时，这特别有用。

此按键仅在 FlexDesigner 运行时有效。目前它也仅在 Windows 版本的 FlexDesigner 中存在。

## 在 FlexDesigner 中

![1745502420295](/image/keyboard_layout_selector/1745502420295.png)

所需的键盘布局/输入法可以在 FlexDesigner 中定义。

## 在 Flexbar 上

按按键切换到定义的键盘布局。
