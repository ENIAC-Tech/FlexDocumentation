# 时钟

在您的 Flexbar 上显示实时时钟

## 在 FlexDesigner 中

![1745504831953](/image/clock/1745504831953.png)

您可以使用标准时间格式代码自定义时间显示格式。我们使用 %X 符号来控制时钟的显示方式，支持以下格式代码：

> 要显示 % 符号，请使用 %%

| 格式 | 描述                                                            |
| ------ | ---------------------------------------------------------------------- |
| %a     | 缩写星期名称                                               |
| %A     | 完整星期名称                                                      |
| %b     | 缩写月份名称                                                 |
| %B     | 完整月份名称                                                        |
| %c     | 日期和时间表示                                           |
| %d     | 月份中的日期 (01-31)                                               |
| %H     | 24 小时格式的小时 (00-23)                                             |
| %I     | 12 小时格式的小时 (01-12)                                             |
| %j     | 年份中的日期 (001-366)                                              |
| %m     | 月份作为十进制数字 (01-12)                                      |
| %M     | 分钟 (00-59)                                                         |
| %p     | AM 或 PM 标识                                                   |
| %S     | 秒 (00-59)                                                         |
| %U     | 以第一个星期日为第一周第一天的周数 (00-53) |
| %w     | 以星期日为 0 的星期几作为十进制数字 (0-6)                     |
| %W     | 以第一个星期一为第一周第一天的周数 (00-53) |
| %x     | 日期表示                                                    |
| %X     | 时间表示                                                    |
| %y     | 年份，最后两位数字 (00-99)                                          |
| %Y     | 年份                                                                   |
| %Z     | 时区名称或缩写                                          |
| %%     | 一个 % 符号                                                               |

您也可以在下拉面板中选择预设的时间格式。

![1745504954685](/image/clock/1745504954685.png)

时钟支持自定义字体和背景设置，但我们不建议使用图像作为背景，因为这可能会增加加载时间。
