# Flexbar 设置

Flexbar 设置按键在设备上打开配置页面。它允许控制设备选项，如屏幕亮度、自动睡眠等。需要先将按键添加到 Flexbar，然后才能在 Flexbar 上访问设置。

![1744945993898](/image/flexbar_setting/1744945993898.png)

## 在 FlexDesigner 中

除了标准视觉选项外，此按键在 FlexDesigner 中没有任何额外的可配置功能。

## 在 Flexbar 上

![1743991555870](/image/flexbar_setting/1743991555870.png)

按按键打开设置页面。从左到右，它提供以下设置：

1. 睡眠超时：设备在给定时间无活动后进入睡眠模式。向右滚动到底（更短的时间）以禁用此功能。我们强烈建议启用此功能以减少 OLED 屏幕的烧屏。
2. 屏幕亮度：设置屏幕亮度。
3. 旋转屏幕：将显示旋转 180 度。主页和返回按键分配也遵循此设置。
4. 触觉开关：启用或禁用触觉（振动）反馈。支持完全关闭振动、仅禁用滑块和滚轮的振动，或启用所有振动。
5. 自动睡眠：启用此功能后，Flexbar 将跟随您的计算机进入和退出睡眠模式。需要重启 Flexbar 才能使此设置生效。
6. 通信协议：在 CDC 和 HID USB 设备类之间切换。CDC 更快但在您的系统中暴露一个额外的串行端口。如果您不知道这意味着什么，建议使用 CDC。
7. 设备信息：显示硬件版本、制造日期、固件版本和固件构建日期。
8. 设备详情：显示设备 ID、设备名称和设备上的剩余存储空间。

此外，向右滚动页面以显示 `ROLLBACK` 按钮。这允许您回滚固件。
