# RGB 灯带

RGB 灯带功能在 Flexbar 上显示全屏动态 RGB 彩虹灯带。

![1744945802319](https://file+.vscode-resource.vscode-cdn.net/c%3A/Users/tongy/Develop/FlexDocumentation/docs/source/functions/gadgets/image/rgb_strip/1744945802319.png)

## 在 FlexDesigner 中

![1744945886816](/image/rgb_strip/1744945886816.png)

FlexDesigner 在功能页面中提供了 RGB 灯带的几个设置：

1. 颜色模式：渐变颜色的插值方法，支持 HSV 和 RGB 两种模式
2. 设置 RGB 灯带的起始和结束颜色。颜色模式会影响两种颜色之间的插值方式。
3. 方向：设置动画方向
4. 播放速度：设置动画速度
5. 颜色宽度：设置颜色重复前的宽度/长度

注意：这只是进入 RGB 灯带屏幕的入口。因此您可以根据自己的喜好自定义其外观（背景和前景）。

## 在 Flexbar 上

在 Flexbar 上按下按键进入 RGB 灯带屏幕。按返回键或主页键退出。
