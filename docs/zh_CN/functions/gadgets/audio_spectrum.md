# 音频频谱

音频频谱按键在 Flexbar 上显示实时音频频谱。

![1744945837496](/image/audio_spectrum/1744945837496.png)

## 在 FlexDesigner 中

此按键有 5 个设置选项，可在 FlexDesigner 的功能选项卡中找到：

![1744718971816](/image/audio_spectrum/1744718971816.png)

1. 输入设备：为音频频谱按键选择音频源。选择回环以可视化主机计算机上当前播放的音频。
2. 频谱模式：在可用的频谱显示视觉样式之间选择。
3. 颜色：为频谱显示选择颜色。
4. 颜色模式：渐变颜色的插值方法，支持 HSV 和 RGB 两种模式。
5. 峰值保持条：为频谱显示运行峰值条。

对于 macOS 用户：目前仅支持麦克风输入。要在 Mac 上显示音频频谱，目前需要使用第三方软件（如 blackhole）创建音频回环虚拟设备。请查看相关第三方软件的文档以获取安装指南。
