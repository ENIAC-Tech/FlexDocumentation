# 插件

本文档介绍了如何在 FlexDesigner 中使用插件功能，该功能允许您为 FlexDesigner 添加更多自定义功能。

If you have programming knowledge, you can also develop your own plugins based on our [PluginSDK](../sdk/getting_started).

## 导入插件

您可以点击按钮库右上角的 + 按钮从链接或文件导入插件。文件必须是打包的 .flexplugin 文件，链接必须指向结构正确的 GitHub 仓库，例如 https://github.com/ENIAC-Tech/Plugin-ScreenMirror。

![1742265313124](/image/plugins/1742265313124.png)

导入后，插件将显示为按钮库。

![1742265946738](/image/plugins/1742265946738.png)

您可以将插件中的按钮拖拽到编辑区域，像使用内置按钮一样使用它们。

![1742266238153](/image/plugins/1742266238153.png)

您还可以在设置界面的应用程序选项卡下管理插件的全局设置（如果可用）。

![1742267167382](/image/plugins/1742267167382.png)

## 管理插件

点击信息按钮查看插件的详细信息。在这里您可以更新或删除插件。

![1742265894863](/image/plugins/1742265894863.png)

您可以在设置界面的项目选项卡下查看当前项目正在使用哪些插件。如果版本不匹配或 插件缺失，系统会提示您安装它们。

![1742266301972](/image/plugins/1742266301972.png)

您可以在设置界面的插件选项卡下查看和管理所有已安装的插件。

![1742266336647](/image/plugins/1742266336647.png)
