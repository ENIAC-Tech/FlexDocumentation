# 页面编辑器

在页面编辑器中，您可以管理 Flexbar 设备，预览和编辑页面。您可以使用鼠标滚轮缩放并拖动虚拟 Flexbar。

![1742261812783](/image/getting_started/1742261812783.png) Feature descriptions:

1. 适应屏幕：点击可重置 Flexbar 的缩放比例和位置
2. 树状视图：点击可通过树结构浏览所有子页面和按键，便于在多个子页面间快速切换
3. 保存您的更改
4. 撤销
5. 重做
6. 按键临时存储：您可以将按键临时存放在此处，便于后续使用
7. 设备总览：在此处选择要上传的设备
8. 将配置上传到设备
9. 页面滚动：当元素超出页面宽度时，可使用两侧的滚动按钮浏览界面
10. 抽屉按钮：点击可打开抽屉。抽屉中的按键不会随主页面变化，适合放置常用按键
11. 预览界面：可拖动按键重新排序，或从按键库拖入新按键
12. 存储状态指示：您的配置已保存到 Flexbar，并显示存储空间使用情况。按键本身占用空间较小，GIF 动图占用较大

## 按键子菜单

右键点击按键可打开菜单。

![1742262258711](/image/getting_started/1742262258711.png)

功能顺序如下：

1. 复制当前按键
2. 在当前页面创建当前按键的副本
3. 剪切当前按键
4. 复制当前按键外观
5. 将已复制的外观粘贴到当前按键
6. 删除当前按键
7. 将当前按键保存为图片（部分按键不支持）

## 页面子菜单

在页面编辑器任意位置右键可打开页面子菜单。

![1742262402981](/image/getting_started/1742262402981.png)

功能顺序如下：

1. 将已复制的按键粘贴到当前页面
2. 清除自动记忆的样式
3. 关闭虚拟界面
4. 将当前页面保存为图片（部分按键不支持）
5. 将每个按键分别保存为图片（部分按键不支持）
