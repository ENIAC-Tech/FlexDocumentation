# 快速开始

本文档介绍 FlexDesigner 的布局、功能和使用方法。

## 概览

![1742266521118](/image/getting_started/1742266521118.png)

FlexDesigner 的主界面由三个部分组成：

1. [Page Editor](page_editor): This area displays the same effects as Flexbar, allowing you to preview and adjust each interface of Flexbar
2. [Key Editor](key_editor): Here you can edit the appearance and functionality of keys
3. [Key Library](key_library): Lists all preset/imported keys that you can drag and drop into the page editor or key editor
4. [Toolbar](toolbar): Contains file management, software configuration, and other functions.
