# 工具栏

工具栏包含文件管理、软件配置和其他功能。

## 文件

![1742266545659](/image/getting_started/1742266545659.png)

功能按顺序排列：

1. 创建新的项目文件 (.flexbar)
2. 打开项目文件
3. 保存当前更改到文件
4. 另存为
5. 导出当前页面到文件 (.flexpage)
   > 将使用父页面的标题和图标
   >
6. 从文件导入页面

## 设置

在设置界面中，您可以管理软件、项目、设备等。

## 系统

![1742266967336](/image/getting_started/1742266967336.png)

1. 设置软件语言
2. 设置软件主题颜色
3. 设置开机自启动
4. 如果勾选，新按键将使用最后编辑的外观；否则将保持默认外观

## 应用程序

管理不同应用程序和您登录账户的全局设置。

![1742267064399](/image/getting_started/1742267064399.png)

## 项目

在此页面浏览和修改项目设置。

![1742267257127](/image/getting_started/1742267257127.png)

1. 垂直模式：启用时，所有按键图标和标题将旋转90°
   > 此模式可能会导致某些按键出现问题
   >
2. 当前项目中已安装的插件列表

## 设备

1. 已连接设备列表
2. 设备信息概览
3. 设备设置
4. 手动固件更新
   > 您通常不需要手动更新固件
   >

设备设置页面③如下所示，您可以在此更改设备名称和颜色。
