# ツールバー

ツールバーから、ファイル操作や FlexDesigner の設定などにアクセスできます。

## ファイル

![1742266545659](/image/getting_started/1742266545659.png)

機能の順序:

1. 新しいプロジェクトファイル（.flexbar）を作成
2. プロジェクトを開く
3. 変更をファイルに保存
4. 名前を付けて保存
5. 現在のページをファイル（.flexpage）に書き出す
   > 親ページのタイトルとアイコンを使用します
   >
6. ファイルからページをインポートする

## 設定

設定では、ソフトウェア・プロジェクト・デバイスなどを管理できます。

## システム

![1742266967336](/image/getting_started/1742266967336.png)

1. 表示言語の設定
2. テーマカラーの設定
3. OS ログイン時に自動起動
4. オンにすると、新規キーは直前に編集した外観を引き継ぎます。オフのときはデフォルト外観のままです

## アプリケーション

連携アプリやログインアカウントごとの全体設定を管理します。

![1742267064399](/image/getting_started/1742267064399.png)

## プロジェクト

プロジェクト設定の確認と変更

![1742267257127](/image/getting_started/1742267257127.png)

1. 縦置きモード: 有効にすると、すべてのキーのアイコンとタイトルが 90° 回転します。
   > このモードでは一部のキーで問題が発生する可能性があります
   >
2. このプロジェクトで使っているプラグイン一覧

## デバイス

接続中の Flexbar などを管理します。

![1742272903108](/image/getting_started/1742272903108.png)

インターフェースの説明:

1. 接続機器一覧
2. デバイス情報の概要
3. デバイス設定
4. ファームウェアの手動アップデート
   > 通常、ファームウェアを手動で更新する必要はありません
   >

以下のデバイス設定ページ③では、デバイス名と色を変更できます。
