# ページエディター

ページエディターでは Flexbar を管理し、ページのプレビューと編集ができます。マウスホイールでズームし、Virtual Flexbar をドラッグして操作できます。

![1742261812783](/image/getting_started/1742261812783.png) Feature descriptions:

1. 画面に合わせる: Flexbar のズームと表示位置をリセットします。
2. ツリービュー: ページとキーを階層表示し、サブページ間を素早く移動できます。
3. 変更を保存
4. 元に戻す
5. やり直し
6. キーの一時置き場: あとで使うキーをここに退避できます。
7. デバイス一覧: アップロード先の Flexbar を選びます
8. 設定をデバイスへアップロード
9. ページの横スクロール: 幅が足りないときは左右のボタンで表示範囲を移動します。
10. ドロワー: 開くとメインページとは独立した領域にキーを置けます（常用キー向け）
11. プレビュー領域: キーをドラッグして並べ替え、Key Library から新しいキーを追加
12. ストレージ表示: Flexbar 上の保存容量の使用状況です。キー自体は軽量ですが、GIF は容量を使います

## キーのサブメニュー

キーを右クリックしてメニューを開きます。

![1742262258711](/image/getting_started/1742262258711.png)

機能の順序:

1. 現在のキーをコピーする
2. 現在のページに現在のキーの複製を作成します
3. 現在のキーをカットする
4. 現在のキーの外観をコピーします
5. コピーした外観を現在のキーに貼り付けます
6. 現在のキーを削除します
7. 現在のキーを画像として保存 (一部のキーには適用されません)

## ページのサブメニュー

ページ エディター内の任意の場所を右クリックして、ページのサブメニューを開きます。

![1742262402981](/image/getting_started/1742262402981.png)

機能の順序:

1. コピーしたキーを現在のページに貼り付けます
2. 自動記憶されたスタイルをクリアする
3. 仮想 UI を閉じる
4. 現在のページを画像として保存 (一部のキーには適用されません)
5. 各キーを個別の画像として保存（一部のキーでは利用できません）
