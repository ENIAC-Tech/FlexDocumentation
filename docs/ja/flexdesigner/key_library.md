# Key Library

Key Library には、エディターへドラッグ＆ドロップできる利用可能なキーが一覧表示されます。

![1742263121475](/image/getting_started/1742263121475.png)

機能の説明:

1. キー検索
2. キーカテゴリのフィルター: Key Library の表示を切り替えます
3. ファイルまたはリンクから Key Library 用データやプラグインを取り込む
4. クイックナビ: クリックで該当の Key Library へ移動
5. Key Library: クリックで折りたたみ／展開。入れ子のサブライブラリに対応
6. キー: エディターへドラッグ＆ドロップして配置

> インポートした `flexpages` やインストール済みのプラグインもここに表示されます
