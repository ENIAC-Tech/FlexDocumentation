# アプリケーションを開く

アプリケーションを開くキーを押すと、ユーザー定義のアプリケーションまたはフォルダーが開きます。

![1744946027052](/image/open_application/1744946027052.png)

## FlexDesigner で

開くアプリケーションまたはフォルダーは、FlexDesigner の機能タブで定義できます。パス入力ボックスの右側には 3 つのボタンがあります。 1 つ目ではフォルダーを選択でき、2 つ目では起動するアプリケーションを選択できます。 3 番目のボタンを使用すると、新しいプロファイルを Flexbar にアップロードする前に、コンピュータ上で直接テスト実行を行うことができます。テスト実行では、Flexbar のキーが押された場合と同じ操作を実行する必要があります。

![1744712900295](/image/open_application/1744712900295.png)

1. 開くパスを選択します。このパスは、Windows のファイル エクスプローラー、MacOS の Finder、Linux のデフォルトのファイル マネージャーで開きます。
2. 開くファイルまたはアプリケーションを選択してください
3. コンピューターでテストを実行する

## Flexbar 上で

キーを押して、FlexDesigner で定義されたアプリケーションまたはフォルダーを起動します。
