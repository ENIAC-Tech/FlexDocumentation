# 循環キー

循環キーは、押されると複数のキー間を循環します。現在表示されているキーのみが実行されます。複数の操作を一度に実行する必要がある場合は、「シーケンスキー」を確認してください。

## FlexDesigner で

![1744985015552](/image/cycled_keys/1744985015552.png)

循環キーは他のキーの単なるコンテナであるため、通常の背景および前景の設定はありません。使用できる唯一のタブは関数タブであり、循環するキーのリストを定義できます。

キーを定義するには、目的のキーを右側のペインから中央の領域にドラッグ アンド ドロップします。機能タブでは、サイクル キーと一緒に使用できるキーのみが表示されることに注意してください。 **キーをダブルクリックすると、その特定の機能をさらに編集できます。**

デフォルトでは、キーは順番に循環されます。アクションリストの右上にある順序ボタンをクリックして、ランダムな順序に切り替えることもできます。

追加されたキーごとに、外観を個別にカスタマイズできます。目的のキーをクリックして強調表示し、前景と背景のタブに切り替えてカスタマイズします。追加したキーの機能タブは、キーをダブルクリックすることで開きます。

循環キー の最も一般的な用途は、メディアの再生と一時停止を制御することです。右側から 2 つのメディア キーを [循環キー] リストにドラッグし、対応するアイコンと色を設定できます。

## Flexbar 上で

キーを押すと、現在表示されているキーが実行されます。完了すると、キー上に次のキーが表示されます。
