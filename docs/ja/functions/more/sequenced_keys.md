# シーケンスキー

sequenced-keys は、複数のキーが連続して押されたかのように、押されると複数のキーを実行します。リスト内の 1 つのキーだけを一度に実行する場合は、「循環キー」をチェックアウトします。

## FlexDesigner で

![1744985000268](/image/sequenced_keys/1744985000268.png)

実行するキーのリストは機能ページで定義できます。

キーを定義するには、目的のキーを右側のペインから中央の領域にドラッグ アンド ドロップします。 Note that when in the function tab, only keys that can be used with cycle buttons would be displayed.

アクション リストの右上には、その動作を制御するいくつかの設定があります。

- アクション間の遅延: アクションは順番に実行されます。各アクションの後、ソフトウェアは一定時間待機します (コンピューターのパフォーマンスやその他の要因の影響を受ける可能性があります)。
- スケジュールに追加: スケジュールに従ってアクションのリストをトリガーできます。このボタンを使用してスケジュール (毎週月曜日の午前 9 時など) を定義すると、このシーケンスがスケジュールに従って自動的に実行されます。スケジュールをキャンセルするには、スケジュール ページの削除ボタンを使用します。
- 順序: デフォルトでは、キーは順番に (順次に) 実行されます。アクションリストの右上にある順序ボタンをクリックして、ランダムな順序に切り替えることもできます。

シーケンスされたキーでは、(右側の Key Library ペインにある) 利用可能な「more」カテゴリに 2 つの追加のフロー制御「キー」があります。

- 遅延: 定義された時間だけ次のアクションの実行を遅らせます。時間はグローバル遅延設定に加えて追加されます。
- 繰り返し: 繰り返しグループ内のアクションの実行を、定義された回数繰り返します。反復回数は、反復グループの右上の入力ボックスで定義します。繰り返しグループは入れ子にすることもできます。

追加したキーの機能タブは、キーをダブルクリックすることで開きます。

## Flexbar 上で

ボタンを押すと、現在表示されているキーが実行されます。完了すると、次のキーがボタンに表示されます。
