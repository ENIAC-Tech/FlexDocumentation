# タイムライン

このドキュメントでは、Premiere Pro のタイムラインのプレビューと Flexbar のコントロール機能の使用方法について説明します。

## FlexDesigner で

この機能は、Key Library の「Adobe」カテゴリにあります。

![1743306979328](/image/timeline/1743306979328.png)

- **アプリケーション**: 現在、Premiere Pro でのみサポートされています。
- **モード**: タイムライン モードとサムネイル モードのどちらかを選択します。
  - サムネイル モードでは Adobe Media Encoder を介してレンダリングする必要があるため、パフォーマンスに影響を与える可能性があります。

## Flexbar 上で

- **タイムライン モード**: タイムラインをプレビューおよびスクラブできます。

![1743307039513](/image/timeline/1743307039513.png)

- **サムネイル モード**: 各セグメントをサムネイルでプレビューできます。スクラブすると、より正確なプレビューが表示されます。

![1743307100773](/image/timeline/1743307100773.png)
