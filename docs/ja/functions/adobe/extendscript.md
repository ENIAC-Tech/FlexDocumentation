# Adobe ExtendScript

このドキュメントでは、Adobe アプリケーションで ExtendScript をワンクリックで実行する方法について説明します。

![1743306598661](https://file+.vscode-resource.vscode-cdn.net/c%3A/Users/tongy/Develop/FlexDocumentation/docs/source/functions/adobe/image/extendscript/1743306598661.png)

## FlexDesigner で

この機能は、Key Library の「Adobe」カテゴリにあります。

![1743306772781](/image/extendscript/1743306772781.png)

スクリプトを実行する対象の Adobe アプリケーションを選択し、以下のコードエディターでスクリプトを編集します。

## Flexbar 上で

Flexbar にアップロードしたら、対応するキーをクリックするだけで、割り当てられた ExtendScript が実行されます。
