# クリップボード

クリップボード機能を使用すると、ファイル、画像、またはテキストを 1 回のクリックでクリップボードにすばやくコピーでき、必要な場所に簡単に貼り付けることができます。

![1745471330502](/image/clipboard/1745471330502.png)

## FlexDesigner で

![1745471367411](/image/clipboard/1745471367411.png)

まず、右側の + アイコンをクリックして、新しいクリップボード項目を作成します。

![1745471398426](/image/clipboard/1745471398426.png)

- 名前: 後で簡単に識別できるように、クリップボード項目に名前を付けます。
- テキスト: クリップボードにコピーするテキストの内容を入力します。
- ファイルまたは画像: クリップボードにコピーするファイルまたは画像を選択します

作成したら、クリップボード項目を選択するだけでセットアップが完了します。

## Flexbar 上で

対応するボタンを押すだけで、Flexbar がコンテンツを自動的にクリップボードにコピーして貼り付けます。
