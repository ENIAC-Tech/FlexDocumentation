# ステッカーパック

ステッカー パック キーを押すと、ステッカー (ミームや任意の画像など) がステッカー パックからアクティブな入力ボックスに挿入されます。

## FlexDesigner で

![1744984574600](/image/sticker_pack/1744984574600.png)

ステッカーはステッカー パックにまとめられています。ステッカー パックは、FlexDesigner で使用できるすべてのステッカーのライブラリです。つまり、単一のキーに設定されたステッカー パックは、すべてのステッカー パック キー間で共有されます。ソフトウェアは、ステッカー パックを整理するためのいくつかの基本機能を提供します (ソフトウェアのボタンの順序に従って)。

- ステッカー パックのインポート: 以前にエクスポートしたステッカー パックを FlexDesigner からインポートします。
- 新しい画像を追加: コンピュータ上の画像ファイルを選択し、ステッカー パックに追加します。
- クリップボードから追加: 前にコピーした画像をステッカー パックに貼り付けます。
- ステッカー パックのエクスポート: 現在のステッカー パックをバックアップまたは共有のために単一のファイルにエクスポートします。

ステッカー パックから画像を削除するには、画像を右クリックして [削除] をクリックします。ステッカー パックから複数の画像を削除するには、画像の上にカーソルを置いたときに画像の右上隅にあるチェックボックスを使用して画像を選択し、任意の画像を右クリックして、[選択したすべてを削除] をクリックします。

特に、これらの操作は前景設定で使用されるアイコン パックでも同じです。ただし、アイコン パックとは異なり、複数のステッカー パックの管理はサポートされていません。

各キーに割り当てることができるステッカーは 1 つだけです。ステッカー パックから目的のステッカーをシングルクリックして選択します。ステッカー パック領域の上部にあるプレビュー領域に表示されるはずです。

## Flexbar 上で

Flexbar のキーを押して、定義されたステッカーをコンピューター上の現在アクティブな入力ボックスに挿入します。

## ヒント

ソフトウェアは複数の形式をサポートしていますが、互換性はターゲット ソフトウェアにも依存します（GIF をまったくサポートしていないメッセージング ソフトウェアに挿入する場合など、Flexbar は魔法のようにアニメーション GIF をそこに挿入できません）。互換性を最大限に高めるために、JPEG および GIF 形式のみを使用することをお勧めします。
