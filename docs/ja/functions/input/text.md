# 文章

テキスト キーは、コンピュータ上のアクティブな入力ボックスにテキストを挿入します。このキーは、標準の USB キーボードで押されるキーをエミュレートするため、キーボードに直接入力できるもののみをサポートできます。他の文字が必要な場合は、代わりにテキスト/絵文字キーの使用を検討してください。

## FlexDesigner で

![1744984788098](/image/text/1744984788098.png)

テキストは、FlexDesigner の関数タブで定義できます。入力ボックスを拡大するには、破線の三角形を入力ボックスの右下にドラッグします。

## Flexbar 上で

キーを押して、定義されたテキストをアクティブな入力ボックスに挿入します。
