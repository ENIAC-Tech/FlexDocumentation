# キーボードとマウス

キーボードとマウスのキーは、ワンクリックでキーとマウスイベントを送信します。 1 つの使用例は、「Ctrl + クリック」または「Ctrl + スクロール」などのショートカットを実装するために使用することです。

この機能は、標準の USB キーボードとマウスのセットをエミュレートします。 FlexDesigner を実行していなくても、どのデバイスでも動作します。

![1744983810565](/image/keyboard_mouse/1744983810565.png)

## FlexDesigner で

This key provides the same set of settings as the keyboard key and the mouse key. Check [keyboard ](./keyboard)and [mouse ](mouse)pages for details.

> このキーのキーボード モードはシングル クリックのみをサポートします

![1744983863690](/image/keyboard_mouse/1744983863690.png)

## Flexbar 上で

Flexbar のキーを押して、定義されたアクションをトリガーします。
