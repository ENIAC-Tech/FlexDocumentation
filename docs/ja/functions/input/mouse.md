# ねずみ

マウス キーは、実際のマウスと同じようにマウス アクションを送信します。

この機能は標準の USB マウスをエミュレートします。 FlexDesigner を実行していなくても、どのデバイスでも動作します。

![1744983987017](/image/mouse/1744983987017.png)

## FlexDesigner で

![1744984004083](/image/mouse/1744984004083.png)

FlexDesigner は、このキーの次の設定を公開します。

- ボタン: 「左」、「右」、「中央」、「戻る」、および「進む」チェックボックスが含まれます。これらは、マウス イベントでこれらのボタンのいずれかを押すかどうかを指定します。
- 移動: トリガーされたときにマウスをどのくらい動かすかを指定します。 「ホイール」と「パン」はそれぞれ垂直スクロール ホイールと水平スクロール ホイールの動きを指定します。
- 絶対位置: チェックすると、移動は相対的ではなく絶対的移動として送信されます。つまり、マウスは指定された距離だけ移動するのではなく、指定された位置に移動されます。
- ダブルクリック: クリックをダブルクリックする必要があるかどうかを確認します。
- クリック後に放す: クリック後にマウス ボタンを放す必要があるかどうかをチェックします。それ以外の場合、マウス ボタンは押された状態になります。

## Flexbar 上で

Flexbar のキーを押して、定義されたアクションをトリガーします。
