# テキスト/絵文字

テキスト/絵文字キーは、コンピュータ上のアクティブな入力ボックスにテキストを挿入します。このキーは絵文字をサポートしていますが、FlexDesigner が実行されている必要があります。絵文字をサポートしていないが、FlexDesigner に依存しないテキスト キーも参照してください。

![1744984750189](/image/text_emoji/1744984750189.png)

## FlexDesigner で

![1744984738429](/image/text_emoji/1744984738429.png)

テキストまたは絵文字（または 1 行または複数行のこれらの組み合わせ）は、FlexDesigner の機能タブで定義できます。絵文字は、サードパーティの入力方法/パネル (macOS の絵文字ピッカーなど) を使用するか、入力ボックスの右側にある絵文字ボタンを使用して挿入できます。入力ボックスを拡大するには、破線の三角形を入力ボックスの右下にドラッグします。

## Flexbar 上で

キーを押して、定義されたテキスト/絵文字をアクティブな入力ボックスに挿入します。
