# マルチメディア

マルチメディア キーは、マルチメディア キーの押下を物理キーボードで押されたかのように送信します。

この機能は、マルチメディア キーを備えた標準の USB キーボードをエミュレートします。 FlexDesigner を実行していなくても、どのデバイスでも動作します。

![1744984037291](/image/multimedia/1744984037291.png)

## FlexDesigner で

![1744984021980](/image/multimedia/1744984021980.png)

押すキーは、FlexDesigner のキータブで設定できます。メニュー ボタンをクリックしてキーを選択します。

## Flexbar 上で

Flexbar のキーを押して、定義されたアクションをトリガーします。
