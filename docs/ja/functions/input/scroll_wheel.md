# スクロールホイール

スクロール ホイール キーは画面上にスクロール ホイールを表示し、操作をキー、マウス、またはメディア コントロール入力にバインドできます。

この機能は、マルチメディア キーを備えた標準の USB キーボードをエミュレートします。 FlexDesigner を実行していなくても、どのデバイスでも動作します。

## FlexDesigner で

![1744984053455](/image/scroll_wheel/1744984053455.png)

スクロール ホイールを左または右にスクロールすると、さまざまなアクションをトリガーできます。アクションは機能タブで指定できます。各方向でキーボード、マウス、マルチメディア、またはこれらのアクションの任意の組み合わせをトリガーできます。

詳細については、キーボード、マウス、およびマルチメディアのページを参照してください。

スクロール ホイールの長さは固定です。ただし、キーがより大きな領域を占めるように設定して、追加のラベルまたはアイコンを表示することは可能です。デフォルトでは、実際のホイールの左側にスクロール ホイール アイコンが表示されます。これを無効にするには、前景タブのアイコン オプションを無効にし、背景ページの幅を最小に設定します。

スクロールホイールの感度は「ステップごとのアクション」で制御できます。デフォルトでは、5 ステップスクロールするごとにアクションがトリガーされます。これを高くすると感度が低くなり、低くすると感度が高くなります。

## Flexbar 上で

スクロール可能なホイールが定義された位置に表示されます。ホイールをスクロールして、定義されたアクションをトリガーします。
