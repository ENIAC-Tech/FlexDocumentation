# OBSスタジオ

Flexbar を使用して、OBSスタジオ をすばやく簡単に制御できます。

## OBSスタジオ をセットアップする

開始するには、**[設定] > [アプリケーション] > [OBS]** で OBSスタジオ の WebSocket サービスを有効にします。

![1743307623980](/image/obs/1743307623980.png)

1. WebSocket設定パネルを開く  
2. [**接続情報を表示**] をクリックします。  
3. **IP**、**ポート**、**パスワード**をコピーします。

![1743307637461](/image/obs/1743307637461.png)

IP、ポート、およびパスワードを対応する入力フィールドに貼り付け、**サーバーのテスト** をクリックします。すべてが正しく設定されている場合は、「接続済み」ステータスが表示されるはずです。
