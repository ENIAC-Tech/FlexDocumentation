# Inventory Monitor

Inventory Monitor を使用すると、Flexbar から直接 Minecraft のインベントリを表示および管理できます。

## FlexLink Mod をインストールする

To use Inventory Monitor, you’ll need to install the [FlexLink Mod](/assets/flexlink-1.0.0.jar) into your Minecraft modpack.

> 現在、FlexLink Mod は Forge バージョン 1.20.1 をサポートしています。

## FlexDesigner で

![1743307444594](/image/inventory_monitor/1743307444594.png)

この機能は、Key Library の「Minecraft」カテゴリにあります。

## Flexbar 上で

インベントリ全体を表示し、任意のアイテムをクリックしてスティーブの手に装備することができます。

> 豆知識: Inventory Monitor の幅を **2170** に設定すると、Flexbar はスクロールなしでインベントリ全体をきれいに表示できます。
