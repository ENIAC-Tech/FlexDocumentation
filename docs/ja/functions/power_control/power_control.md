# 電力制御

電源制御キーは、コンピュータの電源状態を制御するために使用されます。

![1745502078200](/image/power_control/1745502078200.png)

## 寝る

このキーを押すと、コンピュータがスリープ状態になります。

このキーは、FlexDesigner の実行中にのみ機能します。これが望ましくない場合は、「入力」カテゴリの「マルチメディア」キーを使用し、機能を「電源制御」→「スリープ」に設定することを検討してください。マルチメディア キーは FlexDesigner がなくても機能しますが、正確な処理はオペレーティング システムの設定によって異なります。

Flexbar をスリープ状態にするには、「デバイス コントロール」カテゴリの「Flexbar 寝る」キーを確認します。

## シャットダウン

このキーを押すと、コンピュータがシャットダウンされます。

> 権限の制限により、この機能は MacOS および Linux では利用できないことに注意してください。
>
> このキーを押すとコンピュータがただちにシャットダウンされることに注意してください。共通タブの長押し機能と併用することを推奨します。

## 再起動

このキーを押すと、コンピュータが再起動されます。

> 権限の制限により、この機能は MacOS および Linux では利用できないことに注意してください。
>
> このキーを押すとすぐにコンピュータが再起動されることに注意してください。共通タブの長押し機能と併用することを推奨します。
