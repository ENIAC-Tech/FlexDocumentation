# オーディオスペクトル

オーディオ スペクトル キーは、Flexbar にリアルタイムのオーディオ スペクトルを表示します。

![1744945837496](/image/audio_spectrum/1744945837496.png)

## FlexDesigner で

このキーには 5 つの設定があり、FlexDesigner の機能タブで利用できます。

![1744718971816](/image/audio_spectrum/1744718971816.png)

1. 入力デバイス: オーディオ スペクトラム キーのオーディオ ソースを選択します。ホスト コンピューター上で現在再生中のオーディオを視覚化するには、ループバックを選択します。
2. スペクトル モード: スペクトル表示の利用可能な表示スタイルから選択します。
3. カラー: スペクトル表示の色を選択します。
4. カラー モード: グラデーション カラーの補間方法で、HSV モードと RGB モードの両方をサポートします。
5. Peak Hold Bar: スペクトルの実行中のピーク バーを表示します。

macOS ユーザーの場合: 現在、マイク入力のみをサポートしています。 Mac でオーディオのスペクトルを表示するには、現在、サードパーティ ソフトウェア (ブラックホールなど) を使用してオーディオ ループバック用の仮想デバイスを作成する必要があります。インストール ガイドについては、関連するサードパーティ ソフトウェアのドキュメントを確認してください。
