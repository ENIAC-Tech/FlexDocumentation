# RGBストリップ

RGB ストリップ機能は、Flexbar 上に全画面のダイナミック RGB レインボー ストリップを表示します。

![1744945802319](https://file+.vscode-resource.vscode-cdn.net/c%3A/Users/tongy/Develop/FlexDocumentation/docs/source/functions/gadgets/image/rgb_strip/1744945802319.png)

## FlexDesigner で

![1744945886816](/image/rgb_strip/1744945886816.png)

FlexDesigner は、関数ページで RGB ストリップのいくつかの設定を公開します。

1. カラー モード: グラデーション カラーの補間方法。HSV モードと RGB モードの両方をサポートします。
2. RGB ストリップの開始カラーと終了カラーを設定します。カラー モードは、2 つの間でカラーがどのように補間されるかに影響します。
3. 方向: アニメーションの方向を設定します。
4. 再生速度: アニメーションの速度を設定します。
5. 色の幅: 色が繰り返される前の幅/長さを設定します。

注: これは RGB ストリップ画面への単なる入り口です。そのため、外観 (背景と前景) を自分好みにカスタマイズできます。

## Flexbar 上で

Flexbar のキーを押して、RGB ストリップ画面に入ります。戻るキーまたはホームキーを押して終了します。
