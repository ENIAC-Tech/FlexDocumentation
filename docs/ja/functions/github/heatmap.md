# ヒートマップ

ヒートマップ機能は、特定の GitHub ユーザーの貢献ヒートマップを表示します。

![1744983539002](/image/heatmap/1744983539002.png)

## FlexDesigner で

この機能を使用するには、GitHub ユーザー名を FlexDesigner で設定する必要があります。さらに、ユーザー名入力ボックスの隣にある更新ボタンをクリックすると、ヒートマップを手動で更新できます。

![1744983514568](/image/heatmap/1744983514568.png)

## Flexbar 上で

ヒートマップは、この機能に割り当てられた領域に表示されます。このキーに対する対話型アクションはありません。
