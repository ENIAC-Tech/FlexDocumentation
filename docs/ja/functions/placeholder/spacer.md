# スペーサー

スペーサーはキー間の空白スペースを確保します。

![1745501958126](/image/spacer/1745501958126.png)

## FlexDesigner で

スペーサーには背景と前景の設定もあります。デフォルトでは空白で、色はすべて黒に設定されています。ただし、必要に応じてカスタマイズすることもできます。ファンクションキーなしの場合と比較して、ファンクションタブに自動スペース機能が追加されています。ページ内の残りのスペースが自動的に使用されてしまいます。

![1745501987168](/image/spacer/1745501987168.png)

## Flexbar 上で

スペーサーは Flexbar 上に表示され、他のキーと同様にスペースを占有します。ただし、押下はできません。
