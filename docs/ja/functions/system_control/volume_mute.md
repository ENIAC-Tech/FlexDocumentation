# スピーカーミュート

スピーカー ミュート キーを使用すると、システムのオーディオ出力をミュートとミュート解除の間ですばやく切り替えることができます。このキーを押すと、コンピュータのスピーカーが音の出力と消音の間で切り替わります。

この機能はFlexDesigner起動時のみ動作します。 FlexDesigner を使用せずにスピーカーのミュート機能が必要な場合は、システムに内蔵のマルチメディア ミュート キーの使用を検討してください。ただし、これらは常に Flexbar インジケーターと同期しているとは限りません。

## FlexDesigner で

標準の外観カスタマイズ オプションとは別に、このキーには FlexDesigner での追加設定はありません。

## Flexbar 上で

Flexbar のスピーカー ミュート キーをタップして、スピーカーのミュート状態を切り替えます。システム スピーカーのミュート ステータスが他の手段 (キーボード ショートカットやシステム パネルなど) を通じて変更された場合、Flexbar キーが更新されて現在のミュート ステータスが反映されます。
