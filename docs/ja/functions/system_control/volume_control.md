# ボリュームコントロール

ボリュームコントロールキーを使用すると、システムオーディオ出力ボリュームを制御できます。スライダーの音量は、システムの音量設定と自動的に同期されます。

このキーは、FlexDesigner の実行中にのみ機能します。これが望ましくない場合は、「入力」カテゴリの「スクロールホイール」キーを使用し、左/右のアクションを音量ダウン/アップにバインドすることを検討してください。問題は、スクロール ホイール キーでは現在の音量を表示できないことです。

![1745502370652](/image/volume_control/1745502370652.png)

## FlexDesigner で

標準のビジュアル オプション以外に、このキーには FlexDesigner で追加の構成可能な機能はありません。

## Flexbar 上で

Flexbar のスライダーをドラッグして、システムの音量を調整します。他の方法（キーボード ショートカットやシステム パネルによる変更など）で音量を変更すると、その変更は同期され、スライダーにも反映されます。
