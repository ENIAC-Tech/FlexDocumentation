# マイクミュート

マイク ミュート キーを使用すると、システムのマイクのオンとオフをすばやく切り替えることができます。このキーを押すと、コンピュータのマイクがミュートとミュート解除の間で切り替わります。

この機能は、FlexDesigner が実行されている場合にのみ動作します。 FlexDesigner を使用せずにマイクのミュート制御が必要な場合は、システムに内蔵のマルチメディア ミュート キーの使用を検討してください。これらのメソッドは常に Flexbar インジケーターと同期しているとは限らないことに注意してください。

## FlexDesigner で

外観のカスタマイズ オプションを除けば、このキーには FlexDesigner の他の設定はありません。

## Flexbar 上で

Flexbar のマイク ミュート キーをタップして、マイクのミュート状態を切り替えます。マイクのミュート状態が他の手段 (キーボード ショートカットやシステム トレイなど) によって変更された場合、Flexbar キーが更新されて正しいミュート状態が表示されます。
