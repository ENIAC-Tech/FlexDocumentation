# マイクコントロール

マイク制御キーを使用すると、システムのオーディオ入力音量を制御できます。

このキーは、FlexDesigner の実行中にのみ機能します。このキーは、現時点では Windows バージョンの FlexDesigner にのみ存在します。

![1745502389085](/image/microphone_control/1745502389085.png)

## FlexDesigner で

標準のビジュアル オプション以外に、このキーには FlexDesigner で追加の構成可能な機能はありません。

## Flexbar 上で

Flexbar のスライダーをドラッグして、システム入力音量 (通常はマイクの音量) を調整します。
