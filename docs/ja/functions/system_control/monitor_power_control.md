# モニターの電源制御

このキーを使用すると、DDC/CI プロトコルを使用して外部モニターをオフにすることができます。ほとんどのモニターはこのプロトコルをある程度サポートしています。このキーを使用すると、複数のモニターを同時に制御することもできます。モニターの電源がオフになった後は、モニターへの接続が失われるため、このキーでモニターの電源をオンに戻すことはできないことに注意してください。このキーは、FlexDesigner の実行中にのみ機能します。

## FlexDesigner で

![1745502353165](/image/monitor_power_control/1745502353165.png)

接続されているモニターのリストがこのキーの機能タブに表示されます。モニターがサポートしているコントロールも表示されます。各モニターの右側にチェックボックスがあります。チェックされたモニターのみがこのキーで制御されます。

## Flexbar 上で

キーを押すと、選択したモニターの電源がオフになります。
