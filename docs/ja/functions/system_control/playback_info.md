# 再生情報

**Windows のみ**

カバーアート、再生の進行状況、タイトル、アーティストなど、現在のメディアの再生ステータスが表示されます。表示される情報は Windows のメディア情報と同期されます。

## FlexDesigner で

標準の外観カスタマイズ オプションとは別に、このキーには FlexDesigner での追加設定はありません。

## Flexbar 上で

![playback_info](/image/playback_info/playback_info.png)

Flexbar の再生/一時停止キーをタップして、メディア アプリケーションでの再生を制御します。他の手段 (キーボード ショートカットやメディア プレーヤーのクリックなど) で再生を一時停止または再開すると、Flexbar キーが更新されて、正しい再生/一時停止状態が表示されます。

> 再生状態と一時停止状態の外観を自由にカスタマイズできます。
