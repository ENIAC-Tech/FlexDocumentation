# 再生/一時停止

**Windows のみ**

再生/一時停止キーを使用すると、システムでのメディア再生をすばやく切り替えることができます。このキーを押すと、現在アクティブなメディア アプリケーション (音楽プレーヤーやビデオ プレーヤーなど) に再生/一時停止コマンドが送信され、再生状態と一時停止状態が切り替わります。

この機能は、FlexDesigner が実行されている場合にのみ動作します。 FlexDesigner を使用せずに再生/一時停止機能が必要な場合は、システムの組み込みメディア キーを使用できますが、これらのメディア キーは常に Flexbar インジケーターと同期しているとは限りません。

## FlexDesigner で

標準の外観カスタマイズ オプションとは別に、このキーには FlexDesigner での追加設定はありません。

## Flexbar 上で

<img src="/image/play_pause/Pause.png" alt="Pause" width="200"/>

Flexbar の再生/一時停止キーをタップして、メディア アプリケーションでの再生を制御します。他の手段 (キーボード ショートカットやメディア プレーヤーのクリックなど) で再生を一時停止または再開すると、Flexbar キーが更新されて、正しい再生/一時停止状態が表示されます。

> 再生状態と一時停止状態の外観を自由にカスタマイズできます。
