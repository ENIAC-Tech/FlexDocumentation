# オーディオミキサー

オーディオ ミキサー キーを使用すると、さまざまなアプリケーションのオーディオ音量を個別に制御できます。

このキーは、FlexDesigner の実行中にのみ機能します。このキーは、現時点では Windows バージョンの FlexDesigner にのみ存在します。

![1744987068780](/image/audio_mixer/1744987068780.png)

## FlexDesigner で

![1744987057470](/image/audio_mixer/1744987057470.png)

機能ページでは、現在実行中のアプリケーションの一覧が表示されます。アプリケーションごとに、リストの右端近くにチェックボックスがあります。チェックされたアプリケーションのみが音量スライダーによって制御されます。

## Flexbar 上で

Flexbar のスライダーをドラッグして、選択したアプリケーションの音量を調整します。
