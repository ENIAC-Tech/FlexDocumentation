# モニターの明るさの制御

このキーを使用すると、DDC/CI プロトコルを使用して外部モニターの明るさを変更できます。ほとんどのモニターはこのプロトコルをある程度サポートしています。このキーを使用すると、複数のモニターを同時に制御することもできます。このキーは、FlexDesigner の実行中にのみ機能します。

ラップトップでは、「入力」カテゴリの「マルチメディア」キーを使用して画面の明るさを制御する方が簡単であることに注意してください。

## FlexDesigner で

![1745502300597](/image/monitor_brightness_control/1745502300597.png)

接続されているモニターのリストがこのキーの機能タブに表示されます。モニターがサポートしているコントロールも表示されます。各モニターの右側にチェックボックスがあります。チェックされたモニターのみがこのキーで制御されます。

## Flexbar 上で

キーは、音量スライダーと同様の明るさスライダーとして表示されます。スライダーをドラッグして、選択したモニターの明るさを変更します。
