# Flexbar Sleep

Flexbar Sleep キーを使用すると、デバイスを手動でスリープ モードにできます。コンピューターをスリープ状態にするには、「電源制御」カテゴリの「スリープ」キーを確認します。

共通タブでは、任意のページ (ホームページ以外) または特定のキーをスクリーン セーバー (デバイスがスリープ モードに入った後に表示される) として設定できることに注意してください。詳細については、「ナビゲーション」セクションを参照してください。

![1744946008265](/image/flexbar_sleep/1744946008265.png)

## FlexDesigner で

標準のビジュアル オプション以外に、このキーには FlexDesigner で追加の構成可能な機能はありません。

## Flexbar 上で

キーを押してデバイスをスリープ モードにします。
