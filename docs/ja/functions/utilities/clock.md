# クロック

Flexbar にリアルタイムクロックを表示する

## FlexDesigner で

![1745504831953](/image/clock/1745504831953.png)

標準の時間形式コードを使用して、時間の表示形式をカスタマイズできます。 %X シンボルを使用して、次のサポートされている形式コードで時計の表示方法を制御します。

> % 記号を表示するには、%% を使用します。

| 形式 | 説明                                                            |
| ------ | ---------------------------------------------------------------------- |
| %a     | 曜日の略称                                               |
| %A     | 完全な曜日名                                                      |
| %b     | 月の略称                                                 |
| %B     | 完全な月名                                                        |
| %c     | 日付と時刻の表現                                           |
| %d     | 月の日 (01-31)                                               |
| %H     | 24 時間形式の時間 (00 ～ 23)                                             |
| ％私     | 12 時間形式の時間 (01 ～ 12)                                             |
| %j     | 年間の日 (001-366)                                              |
| %m     | 10 進数での月 (01 ～ 12)                                      |
| %M     | 分(00-59)                                                         |
| %p     | 午前または午後の指定                                                   |
| %S     | 2 番目 (00-59)                                                         |
| %U     | 最初の日曜日を第 1 週の最初の日とする週番号 (00 ～ 53) |
| %w     | 日曜を 0 とした 10 進数で表した平日 (0 ～ 6)                     |
| %W     | 最初の月曜日を第 1 週の最初の日とする週番号 (00 ～ 53) |
| %x     | 日付表現                                                    |
| %X     | 時間表現                                                    |
| %y     | 年、下 2 桁 (00 ～ 99)                                          |
| %Y     | 年                                                                   |
| %Z     | タイムゾーンの名前または略語                                          |
| %%     | % 記号                                                               |

ドロップダウン パネルでプリセットの時間形式から選択することもできます。

![1745504954685](/image/clock/1745504954685.png)
