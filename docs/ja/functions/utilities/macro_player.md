# マクロプレーヤー

マクロプレーヤー キーを押すと、記録されたキーボードとマウスのマクロが実行されます。

![1744986195408](/image/macro_player/1744986195408.png)

## FlexDesigner で

![1744986859802](/image/macro_player/1744986859802.png)

1. Flexbar でレコーダー インターフェイスを開きます
2. 現在のマウス座標
3. 現在押されているキー
4. 保存済みの記録を選択します
5. 記録の編集/削除
6. 選択した記録をテストします。**注: これをクリックすると、記録されたマクロがすぐに再生されます**
7. 再生速度を調整する
8. 録音を再生する回数を設定します

「OPEN RECORDER」をクリックしてマクロの記録を開始します。記録の完了は Flexbar 上で行います。

![1744986676793](/image/macro_player/1744986676793.png)

1. 記録の開始/停止
2. 記録時間 (MM:SS)
3. 現在のマウス座標
4. 現在押されているキー
5. この記録を保存します
6. この記録を再生/停止します

記録を保存すると、「機能」タブに表示され、これまでに記録したマクロを選択して使用できます。

記録されたマクロを選択して Flexbar にアップロードしたら、Flexbar でこのキーを押すだけでマクロを再生できます。
