# キーボードレイアウトセレクター

キーボード レイアウト セレクター キーを押すと、事前に定義されたキーボード レイアウト/入力方法に切り替えることができます。これは、コンピュータ上で複数のキーボード レイアウトが有効になっている場合に特に便利です。

このキーは、FlexDesigner の実行中にのみ機能します。また、現時点では Windows バージョンの FlexDesigner にのみ存在します。

## FlexDesigner で

![1745502420295](/image/keyboard_layout_selector/1745502420295.png)

希望のキーボード レイアウト/入力方法を FlexDesigner で定義できます。

## Flexbar 上で

キーを押して、定義されたキーボード レイアウトに切り替えます。
