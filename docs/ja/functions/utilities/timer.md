# タイマー

タイマーの開始時または終了時に一連のアクションを実行できるカウントダウン タイマー。タイマーが終了したときのアラームを設定できます。

## FlexDesigner で

![1745511449741](/image/timer/1745511449741.png)

1. カウントダウン期間を設定する
2. カウントダウン終了時のアラームの種類を選択します: 無効、ボタンアラーム、または全画面アラーム
3. カウントダウン時間表示を非表示にするオプション
4. カウントダウン時間表示の位置
5. Actions to execute when the countdown starts/ends, configured the same way as [Sequenced Keys](../more/sequenced_keys)

## Flexbar 上で

カウントダウンが始まると、半透明の黒いオーバーレイに進行状況が表示されます。カウントダウンが終了するとアラームが鳴ります。

![1745511701014](/image/timer/1745511701014.png)

全画面アラーム:

![1745511776545](/image/timer/1745511776545.png)

Flexbar のタイマー ボタンを長押しすると、時間設定がすぐに開きます。スライダーをドラッグしてカウントダウン時間を調整します。
