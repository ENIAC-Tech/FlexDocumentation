# 自動ホットキー

[オートホットキー](https://www.autohotkey.com/) V2スクリプトをワンクリックで実行できる機能です。

[自動ホットキー](https://www.autohotkey.com/) は、マウス、キーボード、アプリケーション、システム メディアなどを制御できる強力な Windows ユーティリティです。

![1745502544477](/image/auto_hot_key/1745502544477.png)

## FlexDesigner で

![1745502618520](/image/auto_hot_key/1745502618520.png)

[関数] タブには、AHK スクリプトを編集できるシンプルなコード エディターが用意されています。

エディターの右上隅にあるテスト実行ボタンを使用して、スクリプトが適切に動作するかどうかをすばやくテストできます。

## Flexbar 上で

このキーをクリックすると、入力した AHK スクリプトがすぐに実行されます。
