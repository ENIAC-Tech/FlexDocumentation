# Safe Mode

Safe Mode では、Flexbar はどの Profile も読み込みません。このモードは、Profile の読み込み失敗によるクラッシュでデバイスが使用不能になるのを防ぎ、引き続きファームウェアや Profile を更新できるようにするためのものです。

![1743991410209](/image/safemode/1743991410209.png)

## Safe Mode への入り方

### 自動で入る場合

- 新しいファームウェアへ更新したあと、デバイスは自動的に Safe Mode に入ります。Profile を再度ダウンロードする必要があります。
- デバイスがクラッシュを検出すると、自動的に Safe Mode に入ります。Profile を再度ダウンロードしてみてください。クラッシュが続く場合は、サポートおよび改善のため、`contact@eniacelec.com` に Profile を送付してください。

### 手動で入る場合

起動時の LOGO 画面では、左側に目立たない `Enter SafeMode` ボタンがあります。このボタンをタップすると、手動で Safe Mode に入れます。
