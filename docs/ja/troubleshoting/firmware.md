# ファームウェア

ファームウェアとは、Flexbar 内蔵マイコンに書き込まれた組み込みソフトウェアで、工場出荷時にプリインストールされています。更新がある場合は FlexDesigner から案内されます。最新機能と安定性向上のため、定期的な更新をおすすめします。

## ファームウェアを更新する

### 自動更新

ファームウェアの更新が利用可能になると、FlexDesigner に次のような案内が表示されます。できるだけ早めに更新することをおすすめします。

![1743988092470](/image/firmware/1743988092470.png)

### 手動更新

**通常は手動でファームウェアを更新する必要はありません。必要な更新がある場合は、FlexDesigner から通知されます。**

`Setting -> Device` を開きます

![1743984789282](/image/firmware/1743984789282.png)

`UPLOAD FIRMWARE` をクリックし、アップロードの完了とデバイスの自動再起動を待ちます。

**注意: 更新中は電源を切らないでください**

### 更新後、デバイスに「Profile version does not match...」と表示される場合

更新後にこの画面が出るのは正常な動作です。デバイスを最新の状態で動かすため、Profile を再アップロードする必要があります。Profile を再度アップロードすれば解消します。

![1746932309321](/image/firmware/1746932309321.png)

## ファームウェアを更新できない場合

### Flexbar のファームウェアが古い（2.1.1 未満）場合、ごくまれに正しく更新できないことがあります。心配いりません。次の手順に従えば、更新を完了できます。

1. `ファームウェアを更新する` の手順に従って通常どおり更新してください。更新処理（1 分未満）は目を離さないようにしてください。
2. 更新が完了すると、Flexbar は自動的に再起動します。デバイス起動中に LOGO 画面が表示されます。画面の左端に `Enter Safe Mode` があります。LOGO が消える前にクリックして Safe Mode に入ってください。この手順は重要です。時間内に Safe Mode に入れなかった場合は、手順 1 に戻り、ファームウェアを再度更新してから、もう一度試してください。
3. デバイスの Safe Mode 画面に入ったら、FlexDesigner 右上の Upload を一度クリックして Profile を更新するだけです。

## ロールバック

更新後のファームウェアが正しく動作しない場合は、手動でひとつ前のバージョンに戻せます。

> 通常、この操作は必要ありません

### Safe Mode でロールバックする

1. 画面を左にスワイプします

![1743988771303](/image/firmware/1743988771303.png)

2. `ROLLBACK` をクリックして、ひとつ前のファームウェア バージョンに戻します

![1743988710621](/image/firmware/1743988710621.png)

### 設定画面からロールバックする

1. 画面を左にスワイプします

![1743990519882](/image/firmware/1743990519882.png)

2. `ROLLBACK` をクリックして、ひとつ前のファームウェア バージョンに戻します

![1743990587111](/image/firmware/1743990587111.png)
