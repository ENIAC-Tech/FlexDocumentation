# FlexGate

[FlexGate](https://flexgate.enilinx.com/) はオンラインの共有プラットフォームで、Profile、Iconpack、Page、Plugin を簡単に探したり、自分の作品を公開したりできます。

## FlexGate からインストールする

![1744946445046](/image/flexgate/1744946445046.png)

FlexGate から Profile、Iconpack、Page、Plugin をインストールするのはとても簡単です。FlexDesigner を起動した状態で GET をクリックすれば、自動的にダウンロードおよびインストールされます。

## Profile、Iconpack、Page を FlexGate にアップロードする

![1744946552525](/image/flexgate/1744946552525.png)

個人用プロフィール ページを開き、アップロードしたい項目をクリックします。

![1744946938052](/image/flexgate/1744946938052.png)

アップロード前に、次の情報を入力する必要があります。

- Title: コンテンツの名前。簡潔に、目的が分かるように付けます
- Images: 内容が伝わるよう、複数のスクリーンショットを載せることをおすすめします
- Category: コンテンツに最も合うカテゴリを選びます
- Operating System: 対応するオペレーティング システムを選びます
- Version: コンテンツ独自のバージョン番号（FlexDesigner のバージョンとは無関係）
- Description: コンテンツの機能や内容を具体的に説明します

## Plugin を FlexGate にアップロードする

![1744946820834](/image/flexgate/1744946820834.png)

Plugin のアップロードは少し手順が異なります。Plugin は GitHub 上にホストする必要があります。リポジトリの URL を入力すると、FlexGate が有効性を確認します。

> Make sure your repository was created with FlexCLI and has a valid plugin structure. Check out the [SDK documentation](../sdk/) to learn how to create custom plugins

![1744946889859](/image/flexgate/1744946889859.png)

アップロード前に、次の情報を入力する必要があります。

- Images: Plugin の動作が伝わるよう、複数のスクリーンショットを載せることをおすすめします
- Category: Plugin に最も合うカテゴリを選びます

**Q: FlexGate で有料コンテンツを公開できますか？**

**A:** 決済システムは現在開発中です。今後のアップデートで追加する予定です。
