# リリースノート 1.0.2

Hello everyone, FlexDesigner has been updated to version 1.0.2, and the latest version is now available for download on our [official website](https://eniacelec.com/pages/software).
A big thanks to all our beta users for your awesome feedback! We couldn't do this without your support and trust - you guys are really helping us make this thing better every day!


## 主要な機能アップデート

- プラグインのサポート
- マルチデバイスのサポート
- 最適化されたソフトウェアパフォーマンス
- 多言語サポート (現在、英語、中国語、日本語、フランス語、ドイツ語で利用可能)
- 最適化されたページ自動切り替えロジック (ベータ ユーザーのフィードバックから)
- 以前の USB-HID プロトコルと比べて 3 倍高速な新しい USB-CDC プロトコル。ユーザーは両方のモードを切り替えることができます
- ワンクリックで AHK スクリプトを実行できる AutoHotKey サポートを追加しました (ベータ版ユーザーのフィードバックから)

## マイナーな機能アップデート

- インペリアル単位定規 (ベータ版ユーザーのフィードバックより)
- MacOS では、ツールバーをシステム メニュー バーに再配置しました (ベータ ユーザーのフィードバックから)
- 音楽スペクトラム アナライザーがデバイスの変更を自動的に検出するようになりました
- キーボード/マウス マクロが再生速度と残り時間のフィードバックをサポートするようになりました (ベータ ユーザーのフィードバックより)
- フォント検索機能
- 複数行のタイトルのサポート (ベータ ユーザーのフィードバックから)
- スライダー/ホイールの個別の振動トグル設定 (ベータ ユーザーのフィードバックより)
- スペーサー幅の自動調整 (ベータユーザーのフィードバックより)
- ナビゲーション パス要素をクリックしてページに直接アクセスできるようになりました (ベータ ユーザーのフィードバックより)
- アイコンパックのレンダリングパフォーマンスの向上
- SVG アイコンのインポートのサポート (ベータ ユーザーのフィードバックから)
- メインページのウィンドウバインディング機能 (ベータユーザーのフィードバックより)
- 標準の MacOS ショートカット キーのサポート (ベータ ユーザーのフィードバックより)
- RGBライトストリップの方向設定
- テキスト/絵文字入力フィールドに絵文字セレクターを追加しました
- システムロック画面の検出
- 最小スリープ時間は 30 秒になりました
- MacOSトレイアイコンのスタイルを変更
- Flexbar のプレビューの色がデバイスの色に基づいて自動的に変更されるようになりました
- デバイス名と色のカスタマイズ
- バグレポートページを追加しました
- Cycle Button が AB キー機能をサポートするようになりました
- 各種UIの調整と操作性の向上

## バグ修正

- キードラッグ中のメモリリーク
- 負の時間値を許可するタイマーによりクラッシュが発生する
- 8/16 ビット モードを切り替えるときのバイナリ計算機の表示エラー
- コンピュータのスリープ/休止状態後の音楽スペクトラム アナライザの障害
- 点線/破線の境界線と二重実線の境界線のレンダリングが異常になる
- スタートアップの自動起動を無効にする場合の問題
- Flexbar と FlexDesigner の間でテキスト レンダリングの位置が一致しない
- 記録ページを終了してもキーボード/マウスマクロ記録が停止しない
- MacOS アプリケーション終了エラー: 「libc++abi: Napi::Error タイプの例外がキャッチされなかったため終了します」
- ページナビゲーション機能
- ページ切り替え後に音楽スペクトラム アナライザーが動作しない (ベータ ユーザーのフィードバックより)
- MacOS での FlexDesigner シャットダウン ダイアログのブロック (ベータ ユーザーのフィードバックより)
- MacOS マイク許可リクエストの失敗 (ベータ版ユーザーのフィードバックより)
- 65535バイトを超える場合のハードウェアパフォーマンスデータの切り捨て
- プラグイン SDK の描画メソッドの RGB カラー順序が正しくない
- 前景の透明度が効果的でない
- MacOS バージョンでは Dock の存在が必要で、システム トレイでは動作できません (ベータ ユーザーのフィードバックより)
- マイクのないコンピューターでボリュームにアクセスするとスレッドがクラッシュする
- MacOS での CDC インターフェイスの問題
- GitHub ログインのための不要な権限リクエストを削除しました (ベータ ユーザーのフィードバックから)
- さまざまなマイナーなバグ修正
