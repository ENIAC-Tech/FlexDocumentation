# リリースバージョン 1.0.3

## 新機能

- アイコン パックでカバー アイコンの選択がサポートされるようになりました
- よりスムーズで直感的なエクスペリエンスを実現するための UI の改善
- 最初のリリース Linux x86 バージョン

## バグ修正

- アイコンパックのインポートエラーを修正
- プラグインのバージョンチェックの失敗を解決しました
- 言語切り替えに関する問題を修正
- KeyLibrary はサポートされていないオペレーティング システムのライブラリを表示しなくなりました
- キーをシーケンスボタンやサイクルボタンにドラッグできない問題を修正
- ユーザー名にスペースが含まれている場合の起動の問題を解決しました
